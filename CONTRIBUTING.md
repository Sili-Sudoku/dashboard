# Contributing

Small pull requests are welcome. For a new feature, open an issue first so we can check it fits.

```bash
npm install
npm run dev
```

Before you open a PR, run `npm run format`, `npm run typecheck`, `npm run lint` and `npm test`. Commit rules are in
[`docs/CONVENTIONS.md`](docs/CONVENTIONS.md).
