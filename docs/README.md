# Docs

Start with the one that matches what you want to do.

## Make a puzzle

- [`PUZZLE_FORMAT.md`](PUZZLE_FORMAT.md): the JSON of a puzzle and the constraint language. It also has a section
  on using an AI tool to write the JSON.
- [`IMPORT_FIDELITY.md`](IMPORT_FIDELITY.md): which rules survive an import from or an export to f-puzzles,
  SudokuPad and SudokuMaker.

## Understand how it works

- [`ARCHITECTURE.md`](ARCHITECTURE.md): the thesis and the decisions behind it: why the engine knows only generic
  primitives, and what that costs.

## Change the code

- [`CONVENTIONS.md`](CONVENTIONS.md): commits, comments, and the checks to run before a change or a release.
- [`DESIGN.md`](DESIGN.md): the visual identity ("ink & paper").
- [`UI_PLACEMENT.md`](UI_PLACEMENT.md): where a new control goes. Read it before you add a button.
